# One-click-WM
A Win App for watermark
Just a personal project I'm experimenting with.
To add watermark on your photos

## Since I'm Chinese, if you're not a native Chinese speaker, please use translation software for the following parts.

路径不要包含空格，可以包含中文

不要修改内部文件
配置文件在设置.ini中，用笔记本打开，然后修改就行了

目前最可能的报错为：
object of type 'NoneType' has no len()
这个错误的意思的没有对应的EXIF信息(拍摄机型，拍摄参数，地理位置)用来处理，正在修复成警告，下版本修复一下
